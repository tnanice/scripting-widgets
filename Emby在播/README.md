# Emby 在播 · Scripting 桌面小组件

直接读取 N100 工作台 `http://192.168.10.250:8899/api/emby/live?fresh=1`。
沿用工作台的多服务器配置，不需要在手机保存 Emby 管理员密钥。

## 安装

1. 在 iPhone 的 Scripting 中新建脚本项目，命名为「Emby在播」。
2. 创建 `widget.tsx`，复制同名文件的完整内容。
3. 将 `index.tsx` 的内容复制到项目的同名文件。运行项目预览；如提示访问本地网络，请允许。
4. 长按手机桌面 → 添加小组件 → Scripting → 选择中号或大号。
5. 长按新组件 → 编辑小组件 → 选择「Emby在播」脚本。
6. 参数留空显示所有服务器；填写 `Nanflix-HO`、`Nanflix-TX`、`Nanflix-SJC` 或 `Nanflix-US` 可筛选。

中号展示 1 个在播会话，大号最多 4 个；超过时显示剩余数量。
小号展示首个会话。暂停中的会话与工作台一样计入在播，明确标为「暂停」。
显示用户名、片名、集数、设备、播放方式和播放进度；优先展示未暂停会话。
当前接口没有封面字段，因此第一版为文字卡片。

## 网络与刷新

- 手机需要能访问 `192.168.10.250`，通常为家庭 Wi-Fi 或已配置的 VPN。
- 离开可达网络后显示缓存，并标明「离线缓存」及原数据时间；首次连接失败显示连接提示。
- 请求 5 分钟后刷新，实际时间由 iOS 决定，不保证每 5 分钟执行。进度为读取时快照。
- 在 Scripting 运行项目可预览并请求刷新。大号预览可将 index.tsx 的 systemMedium 改为 systemLarge。
- 未找到筛选服务器、服务器故障、接口不可达与无人播放分别呈现，避免把错误当成无人播放。
