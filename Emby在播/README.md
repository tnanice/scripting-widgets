# Emby 在播 · Scripting 桌面小组件

直接读取 N100 工作台 `http://192.168.10.250:8899/api/emby/live?fresh=1`。
沿用工作台的多服务器配置，不需要在手机保存 Emby 管理员密钥。

## 一键安装（推荐）

1. 在 Scripting 中新建脚本项目「Emby在播」。
2. 把本目录 `script.json`、`widget.tsx`、`index.tsx` 复制进项目（首次需要，之后不再手动复制）。
3. 在项目的 **设置 → 远程来源（Remote Source）** 填入：
   ```
   https://github.com/tnanice/scripting-widgets/tree/main/Emby在播
   ```
   自动更新间隔填 `86400`（秒；最小有效值 1800）。
4. 保存。之后 App 会自动从这个 GitHub 仓库检查并拉取更新；也可以在设置里手动点「检查更新」。

> 远程来源要求项目里有 `script.json`。App 解析 GitHub 链接时，`tree` 后第一段是 revision（分支名），
> 随后的路径是脚本子目录，所以上面的链接等价于 main 分支下的 `Emby在播/`。

## 桌面添加小组件

1. 长按手机桌面 → 添加小组件 → Scripting → 选择中号或大号。
2. 长按新组件 → 编辑小组件 → 选择「Emby在播」脚本。
3. 参数留空或填 `auto` 跟随「切换按钮」；填服务器名可锁定该台（如 `Nanflix-HO`）。

## 组件上切换服务器（iOS 17+）

标题栏右侧有一个 **↻ 按钮**，点一下循环切换：

```
全部 → HO → TX → SJC → US → 全部 …
```

- 切换结果立即生效并**持久记住**（所有桌面组件共享同一选择）。
- 按钮旁会显示当前目标（如 `HO`）；显示全部时只留图标。
- 旧系统（iOS 16 及以下小组件不支持按钮交互）或组件「参数」里填了固定服务器名时，以参数为准。

中号展示 1 个在播会话，大号最多 4 个；超过时显示剩余数量。
小号展示首个会话。暂停中的会话与工作台一样计入在播，明确标为「暂停」。

## 网络与刷新

- 手机需要能访问 `192.168.10.250`：家庭 Wi-Fi 或 EasyTier VPN 均可。
- 离开可达网络后显示缓存，并标明「离线缓存」及原数据时间。
- 请求 5 分钟后刷新，实际时间由 iOS 决定。进度为读取时快照。
- 在 Scripting 运行项目可预览并请求刷新（index.tsx 默认预览中号）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `script.json` | 项目元数据 + 远程来源声明（App 更新机制依赖它） |
| `widget.tsx` | 桌面小组件渲染逻辑 |
| `app_intents.tsx` | 切换服务器按钮的交互意图（CycleServerIntent） |
| `index.tsx` | App 内预览入口 |
| `setup.tsx` | 可选：检查远程来源配置状态，给出指引 |

## 更新方式

配置好远程来源后：仓库有新提交 → App 下次检查时发现新版本 → 提示/自动替换文件。
改过 `BASE_URL` 的话注意更新会覆盖 `widget.tsx`，请提前记录自己的修改。
